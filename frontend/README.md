# 🖥️ SportX Frontend (Group 1: Person 1 + Person 2)

## Tech Stack
- **Library:** React (Vite)
- **Styling:** CSS / Tailwind CSS (Cyber-Athletic Dark Theme)
- **Icons:** Lucide React
- **API Client:** Fetch / Axios

## 10 Core Screens to Build
1. `LoginPage.jsx` — Authentication (Login / Signup)
2. `OnboardingPage.jsx` — Goal + Fitness Level + Available Time (10/20/30 min)
3. `DashboardPage.jsx` — Today's Workout, Streak status, Daily Ring
4. `WorkoutPlanPage.jsx` — Selected routine, exercise breakdown, duration
5. `ExerciseDetailPage.jsx` — Movement demonstration and instructions
6. `CameraWorkoutPage.jsx` — Video view, skeleton overlay, rep count HUD & live feedback
7. `SessionResultPage.jsx` — Reps completed, form score %, calories burned, XP earned
8. `ProgressPage.jsx` — Workout history, streak chart, weekly stats
9. `ChallengesPage.jsx` — Campus challenges and leaderboard
10. `ProfilePage.jsx` — Student info, college name, settings & camera privacy

## Setup Command
```bash
cd frontend
npm install
npm run dev
```
